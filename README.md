## About Me

I'm a **Mechatronics Engineer and Junior Robotics Engineer** interested in building reliable, real-world robotic systems. My work and learning focus on robotics software, embedded development, sensor integration, and hardware–software communication.

I enjoy understanding the complete system—from firmware and communication interfaces to ROS 2 applications, debugging, and robot-level integration.

- **Robotics:** ROS 2, robot software, system integration, autonomous robotics fundamentals
- **Programming:** C, C++, Python
- **Embedded systems:** STM32, ESP32, microcontrollers, hardware interfacing
- **Communication:** CAN, UART, SPI, I²C
- **Tools & environment:** Ubuntu/Linux, Git, CMake, colcon, RViz, Gazebo
- **Project interests:** Autonomous Mobile Robots (AMRs), drones/UAVs, robot control, sensor integration, and computer vision

> I aim to build systems that are not only demonstrable, but also understandable, testable, and maintainable.

## Engineering Principles

- **Understand the system:** trace behavior across application, middleware, network, and hardware layers.
- **Test and verify:** distinguish a working demonstration from a validated implementation.
- **Document clearly:** make setup steps, design decisions, and limitations reproducible.
- **Keep learning:** turn concepts into small experiments and progressively more complete projects.
